# OASIS INFOBYTE - Web Development & Designing

## Level 1 - Task 2: Personal Portfolio

A responsive personal portfolio website developed as part of the **OASIS INFOBYTE Web Development & Designing Internship Program**.

The portfolio is designed to showcase my technical skills, projects, background, and contact information in a clean and professional format.

---

## 📌 Project Overview

This personal portfolio acts as a digital résumé and provides an overview of my background as a Computer Science Engineering graduate and aspiring software developer.

The website includes:

- Profile/Hero section
- About Me section
- Technical Skills section
- Projects section
- Contact section
- GitHub and LinkedIn links
- Smooth-scroll navigation
- Responsive design
- Professional footer

---

## 🎯 Objective

The objective of this task is to create a personal portfolio website that showcases:

- Technical skills
- Projects
- Educational/professional background
- Contact information
- GitHub profile
- LinkedIn profile

The project focuses on creating a clean, responsive, and user-friendly portfolio using HTML5 and CSS3.

---

## 🛠️ Technologies Used

- **HTML5** - Semantic website structure
- **CSS3** - Styling and visual design
- **CSS Flexbox** - Flexible layouts
- **CSS Grid** - Skills, projects, and content layouts
- **CSS Media Queries** - Responsive design
- **CSS Variables** - Consistent branding and color management

### JavaScript

JavaScript is not required for the core implementation of this task. The portfolio is built using HTML5 and CSS3, with CSS providing the smooth-scroll behavior and responsive functionality.

## 🎨 Design & Branding

The portfolio follows a consistent visual identity using:

- Dark navy blue
- Blue accent
- White
- Light gray

CSS variables are used to maintain consistency throughout the website.

Example:

```css
:root {
    --primary: #0b1f3a;
    --primary-light: #163b68;
    --accent: #3b82f6;
    --background: #f8fafc;
    --surface: #ffffff;
    --text: #172033;
    --text-light: #64748b;
}
```

The same color system is applied across the navigation, buttons, cards, headings, contact section, and footer.

---

## 📱 Responsive Design

The portfolio is designed to work across different screen sizes:

- Desktop
- Laptop
- Tablet
- Mobile

CSS media queries are used to adjust:

- Navigation
- Hero section
- Profile image
- Skills grid
- Project cards
- Contact cards
- Footer layout
- Typography
- Spacing

The responsive layout is designed to prevent horizontal scrolling and overlapping elements on smaller screens.

## 🚀 How to Run the Project

### Method 1 - Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html`.
4. Select **Google Chrome**.

---

### Method 2 - Using VS Code Live Server

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Open `index.html`.
4. Right-click inside the file.
5. Select **Open with Live Server**.
6. The portfolio will open in your browser.
